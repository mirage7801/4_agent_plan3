# baseline

负责人：郑泽韩
职责：实现同模型、同配置下的单次直接 RTL 生成，作为 Agent 增益基线。

- 输入：题目本身和统一实验配置。
- 必做：只生成一次，不调用 Skill、不接收 EDA 反馈、不重试。
- 产出：原始响应、提取 RTL、生成状态、耗时和配置快照。
- 验收：可与 Agent 在同一批次运行并进行公平比较。
- 禁止：加入修复提示、参考答案、testbench 内容或不同模型配置。

当前实现固定一次 `generate()`，复用 Agent 的初始提示、参数、提取器和 EDA 适配器。验证结果仅用于统计，不会反馈给模型。

## 超时后端自然收尾（2026-10-25）

baseline保持单次生成，使用同一个HTTP客户端和后端收尾屏障；超时仍失败，确认结束后才返回，不能确认则退出3。新增backend观测与时间统计，不加入修复或迟到答案。详见 [后端收尾](../docs/backend-drain-20261025.md)。

## 全局格式对齐（2026-10-28）

格式指令与内部输出统一由model/framing.py维护，RTL支持唯一一层完整answer外包装；JSON仍用answer。来源引用仅归一化空白，禁止跨未引用行拼接。分析失败不做协议重试，使用冻结事实派生；重复同类代码协议错误停止新生成，已有合法候选继续验证。组合限制按适用条件注入。收尾默认120秒，状态接口404/405立即退出3且保留pending。说明与验收见 [格式对齐](../docs/protocol-alignment-20261028.md)。
